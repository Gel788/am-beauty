# AM Beauty

## Product

Premium serum atelier. The homepage is a ritual, not a catalog grid.

## Page type

- Primary: brand showcase / marketing landing
- Secondary: e-commerce catalog (after the hero)
- Density: low
- Interaction: scroll-directed storytelling
- Signature motion: dropper opens and a viscous drop stretches, snaps, then blooms like serum on skin

## Visual direction

Nocturnal glass lab. Signature motion is a real-photo dropper sequence: closed bottle → cap unscrews → pipette extracts → viscous drop stretches → splash blooms open. One accent: oxblood serum.

## Type

- Brand: Italiana (`AM`)
- Display: Prata (Cyrillic)
- Body: Manrope (Cyrillic)

## Motion

GSAP ScrollTrigger pin + Lenis. Reverse scroll closes the dropper. `prefers-reduced-motion` shows a still open dropper without pin/parallax.
